# Rock Paper Scissors Custom Graphics

Place your custom PNG or SVG image graphics in this folder:

- `hand-fist.png` (Shaking/pounding animation frame)
- `hand-rock.png` (Rock hand gesture)
- `hand-paper.png` (Paper hand gesture)
- `hand-scissors.png` (Scissors hand gesture)

The animation class `.animating-hand` in `games/rock-paper-scissors/rock-paper-scissors.css` handles the up-and-down shaking motion!
